# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/ns-0437/SixEyes/security/advisories/new)
rather than a public issue.

## Scope

SixEyes is a read-only analyzer: it reads agent trace files and does not execute them.
Trace files may contain prompts and tool output, so do not attach real traces to public
issues; use redacted or synthetic samples.
